Reading order and headings

Numbers 1–6 on the M1 mobile screen mark this order. The list comes before the map in the DOM so it works as a complete alternative. The map is a single labelled region with its own Skip link.

Default screen (M1, T1, D1)

  1. Skip to results (first focus stop)
  2. header · search field (role search), language, saved
  3. Show: Branches / ATMs / Both (group)
  4. Filters button and applied chips, each removable
  5. main · h1 “Open branches near you”, result count in a live region
  6. Results list · each card is an article with h2 name; then Directions, Call, Save
  7. Map (region) · zoom, locate, Search this area, then pins by distance

Branch detail

  1. Back to results, Previous, Next (“1 of 7”)
  2. h1 branch name, status, Directions, then Call, Save, Share
  3. h2 Address and phone → Opening hours (table, today marked) → Services → What to bring → Open in → Report incorrect info

Dialogs (filters, language, directions)

Focus lands on the dialog’s h1, Tab is trapped inside, Escape closes, and focus returns to the control that opened it.
