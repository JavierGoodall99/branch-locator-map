Design rationale

Capitec Branch Map Locator. Built on the App Design System: blue only, Nunito Sans, 8px scale. All branch data is sample content.

Key decisions

List is the product, map is the context

The three goals (open now, ATM with deposits, travelling) are all answered by a list with a status chip. So the sheet holds the real work and the map backs it up. Every result is reachable without touching the map.

Half-height by default

Trade-off: peek shows more map, full shows more list. Half shows the first card and keeps pins visible, so someone in a hurry gets an answer without dragging. Peek and full are one swipe away.

One filled button per view

Directions is the only filled button on a card and on the detail view. Call and Save are text buttons with labels. This is the choice for a stressed user: one obvious next step.

Open state: icon, word and fill

Three chips: Open (tint fill, tick), Closing soon (dark fill, clock), Closed (outline, moon). They survive greyscale and colour blindness. “Closing soon” means under 60 minutes, which is a product call to confirm.

Pre-permission before the browser prompt

A short explanation first, so a tap on “Don’t allow” is rarer. If location is refused the screen offers search and common cities. It never dead-ends.

“Search this area”, never silent reload

On weak data, a reload you didn’t ask for wastes bytes and moves the list under your thumb. The button is an explicit, labelled choice.

Filters live in one sheet

Seven filters plus sort fit one scroll on a small Android. Applied filters stay visible as removable chips, so the active set is never hidden.

Offline keeps the last results

A quiet banner states the time they were saved and warns hours may have changed. A Capitec customer standing outside a branch with no signal still sees the address.

Languages designed long

Afrikaans and isiZulu strings run 20–40% longer. Chips and buttons wrap, cards grow, nothing truncates. Translations here are placeholders and need professional review.

Older users, tablets

Same 16px minimum text, 44px targets, visible labels everywhere. The panel stays on screen next to the map, and Back to results is always a labelled button.

Additions to the design system

The system is silent on these, so I extended it in the same spirit (blue only, flat, one shadow). Everything else is a stock token.

Known gaps

  • • Unselected chip and input edges fall below 3:1 against white. They are identified by text and a strong focus ring, same as the system. Worth a design-system decision if you want a firmer boundary.
  • • I couldn’t run a screen reader or a real device here. Reading order and contrast are specified and calculated, but need a real keyboard and VoiceOver/TalkBack pass.
  • • The isiZulu and Afrikaans strings are my drafts. Get them reviewed.
